# 待实机验证：追忆增幅与开局龙心脏

用户确认的行为（2026-09-30）。本文件是待实现规范；参数和文字的局部草稿不代表事件机制已经生效。

## 物品及奖励

- 每个新角色在开局取得 **一个**可重复使用的「龙心脏」（Ascended 的 Empowered Soul 道具改成一个统一道具）。其数量和效果不依赖选择的职业；已经创建的角色需要一次性补发逻辑。
- 删除 DLC 追忆 BOSS 的原有多个龙心脏奖励，保留正常追忆、卢恩及其他不相关奖励。新道具不随击杀重复掉落。
- 开局零个符合条件的 BOSS 击败标记时，使用统一道具不增加生命值或攻击力；道具不消耗。
- 每个符合条件的追忆 BOSS 首次击败，只更新永久进度，不立即施加增幅。玩家再次主动使用道具时，从已击败的 BOSS 标记重新计算增幅。
- 「符合条件」是普通追忆增幅的 11 个本体 BOSS 和 10 个 DLC BOSS；葛瑞克、拉塔恩、蕾娜菈、玛莲妮亚四个特殊追忆各自的特殊效果保留，不能静默转换为普通 +5% 层数。

## 数值与互斥

- 普通追忆每位 BOSS 的增幅按最新目标：最大生命值 ×1.05，物理、魔力、火、雷、圣攻击力各 ×1.025；不增加最大 FP 或精力。
- 同一 BOSS 只计一次。共有 n 个符合条件的击败标记时，生命倍率为 1.05^n，攻击力倍率为 1.025^n。重复使用道具刷新到该倍率，不再增加一层。
- 统一道具生效前先移除普通追忆现有增幅；使用普通追忆时应切换离开统一道具模式，或阻止与同一增幅叠加。验证两个使用顺序和重复使用顺序。
- 四个特殊追忆保持原先单独的效果，不视作普通增幅，保留相应文字。

## 事件实现及验证门槛

1. 已定位十个额外龙心脏位于 `ItemLotParam_map` 独立的奖励行：10401、10461、10481、10551、10561、10601、10622、10632、10641、10901。草稿已将这十行的第一物品 ID 和类别置零，保留相邻的追忆、米凯拉的大卢恩、梅瑟莫的火种等奖励。仍需检查每个 BOSS 的永久击败标记、开局发放事件与游戏实际发奖行为。
2. 追忆和统一道具需要可检测的使用触发。击败 BOSS 时只记录进度；使用道具时在玩家身上清除对应旧增幅，再施加当前累计值。需要覆盖重新加载、死亡、传送、周目切换和既有存档；不能把一次使用误当作一次额外击败。
3. 同步改简化动作及视觉效果；仅修改 `EquipParamGoods.goodsUseAnim` 不能证明动作等同「火焰赐予我力量」。需要在游戏里验证声音、特效和动作与实际效果。
4. 用新旧角色测试：零击败、单一 BOSS、多个 BOSS、重复使用、先追忆后龙心脏、先龙心脏后追忆、四个特殊追忆、DLC 奖励、死亡重进和新周目。
