## 两项修改

1. 234 个奖励行继承了外观效果 1950 的关闭状态：`effectTargetSelf`、`effectTargetPlayer`、`effectTargetLive` 等目标标记为 0。现将六个佩戴者兼容目标位设为 1，保持其它奖励参数、倍率、ID、触发链不变。独立差分检查证明只改这 234 行的目标位，全部其它参数行与上一套装设计逐字节一致。此项是明确的模板遗漏；此前事件模拟未检查效果对象标记，不能当作实际增益证明。
2. 308 个套装初始化由 constructor 末尾移至前端。原 constructor 的 `END IF Player Is In World Type` 与 flag 2052 提前退出会阻断末尾的初始化。四组分支模型显示旧位置在任一提前退出条件满足时初始化 0 个奖励事件，新位置均初始化 308 个。原有全部指令顺序保持。未测玩家此次场景是否触发了这些条件，不把这一项宣称为实机已证明的根因。

参数容器继续使用 06 修复后的紧凑 BND 和保守 PARAM 写入，60,003,408 字节，无弃用整表副本。原版单件恢复、本次 Excel 的 26 类意见／12 条单件、四项核心护符倍率、Boss 成长与敌人韧性不回退。

```text

单件：当前单件效果（仅存在时显示）
```
