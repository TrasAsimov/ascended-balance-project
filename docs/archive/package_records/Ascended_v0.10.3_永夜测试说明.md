# v0.10.3 · 永夜事件测试

继承 v0.10.2 的全部参数与资源，仅将 `ModEngine/mod/event/common.emevd.dcx` 换成用户使用 DarkScript3 编译回传的版本。源码在已有统一心脏事件 20007901、20007902 之外初始化 20007903：玩家自己世界中等待主线初始时间标记 100，然后设定 23:45，冻结时间；每 2 秒重新执行。作用是纠正赐福选择白天以及其他时间推进。此前的天气亮度参数维持 v0.10.2：普通天气使用 Ascended 的 51，浓雾等三个配置保持较亮的 50。

**静态验证：**回传的 DCX 是 Kraken 格式，声明解压长度 402,512 字节，比上一版公共事件增加 352 字节；编译包在 Windows 上应先编译、反编译，并核对三个事件和永夜指令。这里再次校验文件 SHA-256、容器头与整包 CRC、其余所有文件逐字节一致。当前环境无法独立解压 Kraken 并复核每一条事件指令，故仍需实机确认。

**测试：**在赐福选择「等到早晨」或「等到正午」，离开菜单观察约 2 秒，确认游戏实际天色与钟点回到夜晚；随后传送到其他区域、死亡复活、再次坐赐福、雨雪及雾天分别检查。注意：固定时间可能影响需要特定时间段推进的任务或 NPC；请记录地点、任务、天气和异常。备份存档，离线使用 ModEngine 并禁用 EAC。

玩家旧版动作文件尚未集成；高跳恢复和弹反动作／判定扩展仍待 A、A+B 两种独立动作文件的实机兼容性结果，此版不宣称修复这两项。
