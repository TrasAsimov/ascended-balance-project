# v0.10.6 套装触发修复与短描述测试版

本完整包继承 v0.10.4 的全部资源，并整合已批准护甲套装和核心伤害平衡。源码依据 c6c81ebb2b3201fc13c6d8acf7feea7502605084。

更新套装奖励的佩戴者对象标记，调整 308 个公共事件初始化位置，保留紧凑 BND 修复。护甲正文只保留套装名、单件效果、两件及满套效果；独立增伤使用 × 倍率表示，固定点数使用 +。原背景文字已替换。

当前写入英文 engus 档案。中文 description_zh.json 为合并数据，缺少匹配的 zhocn 原档案，本包没有伪造中文游戏档案。

安装：关闭游戏，备份存档及现有 ModEngine 文件夹，解压完整包，将其中 ModEngine 内容覆盖原安装路径。regulation.bin 与 event/common.emevd.dcx 必须同时更新。沿用原来的离线 Mod 启动方法。

静态结构、参数、事件、文本和完整包字节核对通过；本版尚未实机验证。先测试启动、读档、保存退出再重载，再用感应未达上限的角色穿霍斯劳 1→2→满套→1 件，检查两件感应 +20 和卸装取消；然后检查出血触发增伤及卸装清理。描述自动换行仍需实机检查。

旧 v0.10.5 安装包不含这些修复。游戏报错或实际数值异常时，请记录穿戴、文件哈希和数值。
