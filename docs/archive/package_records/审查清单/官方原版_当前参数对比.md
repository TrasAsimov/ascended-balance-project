# 最早提供的官方原版与当前参数对比

**比较对象：**用户最早提供的官方 `regulation.bin` 解包为 `work/vanilla_117.bnd`；当前集成版为 `work/pending_spell_boss_bonus.bnd`。二者均为官方 1.17.1 内部版本号 `11711000`，包含相同的 194 张参数表。这里对比的是**官方游戏与当前基于 Ascended 的 MOD**，差异中含 Ascended 原有修改及本项目修改，不应全部归因于本项目。

详细的 [逐表和字段统计](vanilla_to_current_summary.generated.md) 及[完整逐字段 CSV（gzip）](../changes/vanilla_to_current_fields.csv.gz)由 `scripts/report_current_params.py` 生成。相同行省略；新增行不能与不存在的原值相减。15 张表因 Paramdex 定义短于实际行长，报告仅给行级比较，不能宣称逐字段完整。

| 对照范围 | 原版 | 当前 | 如何解读 |
|---|---:|---:|---|
| 参数行总数 | 179,332 | 190,247 | 当前比原版多 10,915 行，主要来自 Ascended 的敌人攻击判定与效果定义。 |
| 共有但内容不同的行 | — | 45,348 | 另外有 133,984 个共有行字节相同。 |
| 可解析字段变化 | — | 159,487 | 含保留字段／填充字段；不能等同 159,487 个可观察游戏效果。 |
| `NpcParam` 行 | 7,045 | 7,187 | +142 个敌人/NPC 定义，4,816 个共有行不同。 |
| `AtkParam_Npc` 行 | 12,855 | 23,093 | +10,238 个攻击判定，10,380 个共有行不同。 |
| `EquipParamWeapon` 行 | 3,636 | 3,638 | +2 行，3,521 个共有行不同，涉及基础伤害、补正、战技与常驻效果。 |
| `SpEffectParam` 行 | 11,354 | 11,834 | +480 行，其中 21 个为本次普通追忆法术子效果。 |
| `Magic` 行 | 317 | 317 | 220 个共有行不同；217 条玩家法术另有逐条 v0.7 审计。 |

## 能直接核对的实际参数例子

| 对象 | 官方原版 → 当前 | 备注 |
|---|---|---|
| 生命成长曲线 `CalcCorrectGraph[100]` 的 `stageMaxGrowVal0…4` | `300/800/1450/1900/2100` → `600/1600/2900/3800/4200` | 成长数值逐项 ×2，武器常驻生命效果置 ×1；实际显示还受其他效果影响。 |
| 托雷特哨笛 `EquipParamGoods[130]` | 当前行与官方行相同 | 恢复了该道具的三处 Ascended 差异；骑乘还受事件／地图及存档条件影响。 |
| 玩家法术示例 `Magic[4000]` FP | 基础 `7` → `10`，追加 `0` → `8` | 这是一个 ID 示例，不代表所有法术采用同一个倍率。 |
| Bandit 起始参数 `CharaInitParam[3003]` | 左手小圆盾、箭矢移除、第二护符 `2090` | 完整初始装备还涉及起源/外观两组角色行，详见职业审计。 |
| 普通追忆 `EquipParamGoods[2002900]` | 使用效果 `20502900` → `321412`；消耗 `1` → `0` | 当前普通追忆设置为可重复使用并赋予增益；对应 `321412` 是 MOD 新行。 |
| 21 个普通追忆的 `SpEffectParam[321412…321455]` | 官方无对应行 → MOD 新行 | 不能拿不存在的原版倍率直接相减；当前普通层为生命 ×1.05、武器攻击力 ×1.025，法术效果待实测。 |

本对比只覆盖 `regulation.bin`。压缩包里的地图、事件、动画与英文文本存在独立修改，其中新增统一心脏事件已编译回读，效果还没有经过游戏内测试。游戏内中文说明可能仍使用官方文本；本报告给出的当前值来自参数解析，不是游戏 HUD 截图。
