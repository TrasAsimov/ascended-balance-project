# v0.10.8 统一整合检查与测试

基于 v0.10.7 完整包。仅整合总控批准且已完成的模块；随机化、完整简中游戏档案、未完成的新改动不在本次范围。

## 已整合

- 套装：234 个中性奖励 `wepParamChange` 从 3 改为 0，其余护甲数值及官方筛选保留。
- 核心：蓄力额外 +300%（系数 4），魔法/祷告攻击力额外 +220%（系数 3.2）。后者是攻击力字段，不保证最终扣血同幅增加。其他核心和 741 件护甲文本不变。
- 额外减益：仅清理明确列出的 12 条自定义效果的额外惩罚。异常累积、触发和状态链保留，发狂瞬发保留；共享效果的 AI 也受影响。
- 心脏：181 场白名单小首领，每场生命/法力/精力上限 +0.2%，武器攻击力/法术直接伤害 +0.1%，组内加算。满白名单分别 +36.2% / +18.1%。贝勒独立提供生命 +5%、攻击/法术 +2.5%，不增加 FP/精力。使用强化之魂手动刷新，重复使用不叠加；已有击败旗标可计入。Ascended 新增遭遇未全部审计。
- 玩家法术异常：以当前 Mod 的正累积值乘 50%，整数就近舍入且最小 1。修改 144 条 Magic 引用，私有 Bullet/AtkPc/SpEffect 分别新增 943/7/33 行，使用 7500000 段，避开心脏 7400000 段。非累积直接伤害、FP 和发作后的爆发/持续伤害不变；触发次数不保证恰好翻倍。复用玩家 Magic 的 AI 同样减半。
- 英文核心和心脏说明同步；中文 JSON 为源合并数据，不是可直接安装的 zhocn 二进制。
