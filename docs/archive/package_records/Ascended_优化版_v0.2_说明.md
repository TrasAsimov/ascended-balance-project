# Ascended 平衡优化版 v0.2

此包继承 **v0.1 的 581 项 FP 调整及事件 ID 修正**，并以玩家实际反馈为依据增加本轮改动。完整包直接使用；小补丁同时包含两份 `regulation.bin` 和已修正的公共事件，覆盖原 Ascended 或 v0.1 均可。

## 本轮规则

| 范围 | 修改项数 | 调整办法 |
|---|---:|---|
| 玩家全局倍率 | 11 | 2,511 件武器共享的效果 `6202065`：最大 HP 7 → **1.5**；移除额外 1.8 倍伤害层，对敌五属性伤害 2 → **1.5**。FP 容量保持原值，便于法术流派测试。 |
| 护符极端倍率 | 20 | 战斧、双头剑、箭矢刺痛、曲剑四枚护符的 3.15–4.7 倍极端伤害降至 1.5 倍。 |
| 区域敌人血量 | 43 | 被 Ascended 再次大幅提高的 43 个区域 HP 倍率恢复对应原版区域阶梯。 |
| 敌人基础血量 | 1700 | 敌对 NPC 基础 HP 上限为对应原版行 **2 倍**；MOD 新行按同模型最近的正常原版行推定。 |
| 敌人异常抗性 | 3969 | 八类伤害承受倍率最低为原版的 **80%**；0 免疫与原版固有免疫保留。 |
| 敌人失衡耐久 | 1229 | 异常升至 9,000／90,000 等的基础失衡耐久恢复对应原版正值。 |
| 敌人攻击上限 | 1493 | 共有攻击行五类数值上限为原版的 **1.5 倍**；原版 0 或 1–9 的特殊值保留。 |
| 战技攻击修正和玩家失衡 | 230 | 部分削弱至原版不足 75% 的玩家攻击恢复原版修正；受削弱的失衡输出恢复原版。 |
| 接触弹反试验 | 564 | 对能明确识别的近战武器攻击启用参数中的接触弹反判定。仅为第一步，见下方限制。 |

新增改动共 **9259 项**；完整的行 ID、英文字段、中文字段说明、前后值、参考行见 CSV。

## 样例

- Malenia 第一阶段 `hp`：25000 → 4978
- Malenia 魔法承伤 `magicDamageCutRate`：0.05 → 0.64
- Margit `superArmorDurability`：9000.0 → 80.0
- Axe Talisman `physicsAttackRate`：4.6999998 → 1.5

**韧性与伤害是不同的数值。** 怪物的 `superArmorDurability` 决定累积多少失衡伤害才倒地；武器、法术和战技自身的失衡攻击值决定每次造成多少失衡。生命伤害还受攻击、属性承伤倍率与区域 HP 倍率等影响。恢复怪物韧性和恢复部分玩家失衡攻击可以让更多攻击经过连续命中触发失衡。

**弹反仍需实机验证。** 原版与 Ascended 共同行的 `NpcParam.parryDefence` 和 `AtkParam_Npc.isDisableParry` 原本没有差异；同时 MOD 改动了大量角色 TAE 动作。这里新启用的是有名称、非投掷且可识别的近战武器攻击的“接触弹反判定”，不能仅凭参数证明每个动作都有受弹反反应、有效窗口，尤其大型 Boss、投射物和新动画。请提供仍无法弹反的具体怪物名称、攻击动作和所用弹反手段，才能继续追查其 TAE 事件。不要将本版视为所有敌人、所有攻击均已可弹反。

## 安装、回退和验证

1. 离线测试前备份存档和原 Ascended 文件夹。将小补丁解压覆盖到 **包含 `ModEngine` 的文件夹根目录**。如果仅部署 `ModEngine/mod`，手动覆盖其中的 `regulation.bin` 与 `event/common.emevd.dcx`。或者直接使用完整包。
2. 实机先确认角色 HP 从原来武器增益的高倍率下降、辉石魔砾等 FP 调整仍在；再用法术、祷告、战技、蓄力重击打同一精英或 Boss，记下命中伤害。
3. 选此前无法失衡的怪物，连续命中测试失衡；对一只人形近战怪用小盾弹反测试多种普通攻击，并记录失败的招式。护符测试前后需要保持相同装备和属性。
4. 如果某处 Boss 攻击过弱或过强、脚本异常，使用备份恢复原 Ascended；需要回退至 v0.1 时覆盖 v0.1 的两份文件与事件文件。

当前 Ascended 参数仍为 **1.16**，对照原版是 **1.17.1**。本版没有把新版原版的行结构移植进 MOD；静态检查证明文件可解密、解压、解析及改动范围正确，不能替代当前游戏版本的实际加载和战斗测试。
