# Ascended Balance v0.10 集成测试快照

这份包继承 v0.9.2 的完整 Ascended 资源，加入截至目前已生成的最新 `regulation.bin`、两份英文物品文本及用户在 Windows 编译回传的 `common.emevd.dcx`。它是待游戏内验证的集成版，不代表龙心脏与追忆机制已完成实测。

主要变化见 `审查清单/v0.5_至今有效改动.md`；官方与当前参数全量统计见 `审查清单/官方原版_当前参数对比.md`。生命成长为官方曲线的两倍；已移除拿武器时附带的生命翻倍与各属性固定 +150。普通追忆的生命倍率 ×1.05、攻击力倍率 ×1.025，并连接 ×1.025 法术伤害子效果。统一龙心脏有中性使用标记和新增事件；四个特殊追忆原有特殊效果保持。

安装：备份存档，在全新的目录完整解压，沿用此前可启动的离线 ModEngine 设置并禁用 EAC。不要与旧测试包混合。分别核对空手、拿普通武器和拿法杖时 HP 与各属性攻击力；新建 Bandit/Vagabond；原有与 DLC 普通追忆；获得血瓶后的龙心脏；先用追忆后用心脏和相反顺序；同一法术、祷告、武器在无增益、单个追忆、统一心脏下的伤害。若表现异常，请记录道具 ID／名字、击败的 BOSS、前后数值、语言和存档阶段。

已完成两份 `regulation.bin`、事件文件、英文文本和 ZIP 条目的字节比对，ZIP CRC 检查通过。**仍未证实**龙心脏开局发放／击败记录刷新／互斥、法术是否双重受益、小 BOSS 自动增益的来源、死亡与重新加载后的持续性、托雷特骑乘、特殊武器被动及追忆使用动作。动作替换按用户要求后续再做。游戏内文本目前只更新英文；中文说明请参考文档。
