## v0.10.9 打包要求

- 只打运行所需 Mod 文件 + 简短 README/安装说明 + SHA256。
- **不要**把开发期 `docs/`、`changes/`、源码脚本、各版本对比、旧 manifest、临时候选、测试报告、source.patch 塞进玩家下载 ZIP。
- 所有开发记录、参数对比、审计、脚本统一保留在 GitHub 仓库。
- ZIP 内不得包含旧版本完整包、旧 regulation 备份、重复文本容器、失败候选或临时文件。
- 对最终 ZIP 做文件清单、重复文件、CRC/解包、关键继承文件哈希和 SHA256 检查。
- Release 说明区分：已实现/静态验证/游戏实测。上述新模块目前均不得写成“已实机验证”。
