# v0.10.5 · 护甲套装与核心平衡集成测试版

2026-10-01。完整安装包继承 v0.10.4，替换已完成的 regulation、公共事件及两份英文物品文本；保留高跳 HKS、新版战技映射、地图、动画和其它资源。

## 本版内容

- 按回传 Excel 的 26 类奖励意见与 12 件单件意见实现：187 个护甲家族、741 件具名护甲，165 个家族有奖励。完整分类、详细套装名和数字见 `Armor_Core/armor_core_integration_20261001.md`。
- 恢复 140 件护甲的原版效果及相关效果链，兼容的 Mod 效果保留。明确例外：蘑菇王冠、黑头罩增伤持续 600 秒；神兽头部力量与灵巧各 +20；小恶魔头罩新增指定增益并保留原版属性。
- 套装奖励使用独立效果与事件，不占原版常驻槽。同类两件与满套伤害奖励按满套总值替换，不同效果并存；按实际部位计件，换装不足或死亡时最多 6 个游戏帧内清除套装奖励及子效果。两部位家族只领取两件档。
- 魔法／祷告护符攻击力系数 ×2.2，蓄力攻击 ×3，跳跃攻击 ×2，普通连段最后一击 ×3.5；防御反击 ×4、处决 ×5、箭矢／弩箭 ×2 保持。攻击力系数不等于最终敌人扣血倍率。
- 并入此前暂存平衡：6,453 条正常敌人失衡耐久 ×1.25；679 条禁用值与 55 条特殊高值不改。大盾护符格挡精力消耗倍率 ×0.5，即减耗 50%。敌人生命沿用 Ascended 恢复方案。
- Boss 心脏主效果及施法子效果保留。先前将两者双计得到法术 ×2.82 的确定结论已撤回；21 层施法子效果约 ×1.68 仍只是待实测模型。
- 两份英文档案更新全部 741 件护甲说明及核心护符说明。简中 JSON 是合并源，尚无匹配原版档案生成的可安装简中 DCX。

## 安装

1. 下载 `Ascended_Balance_v0.10.5_Armor_Core_Integrated.zip` 完整安装包；GitHub 的 Source code ZIP 不是安装包。
2. 使用 ME3，将整个文件夹解压到全新目录，例如 `E:\me3\config\profiles\eldenring-mods\<MOD文件夹>\`。保留 `ModEngine` 目录结构。
3. 备份存档，关闭 EAC，离线测试。先开启 Steam，再运行 `ModEngine\launchmod_eldenring.bat`。完整内容需游戏本体及全部 DLC；初始物品须新建角色检查。

## 验证与待测

已完成模块静态检查：194 张参数表、140 件原版效果装备、167 个效果链节点、61,420 个事件分支用例、15,620 个穿戴／生命场景、256 个原有事件保持、741 件英文说明在两份档案回读。打包另检查输入哈希、ZIP CRC、四份替换文件及所有继承成员逐字节一致。

本版新增护甲、核心倍率和失衡调整尚未游戏实测。优先测试：两件／满套／混搭与改造版计数；换装、死亡、传送与重载清理；血毒腐触发及 600 秒刷新；同条件护符伤害和格挡耗精；事件运行性能。高跳与斗牛剑战技仅有 v0.10.4 的玩家确认。

弹反速度与窗口、完整简中游戏文本、统一心脏动作、随机化、执行者移植仍待完成。旧永夜事件沿用，本版未新增昼夜修复。

## English

This complete test package combines the reviewed armor system and core talisman balance with v0.10.4 resources. It retains the current-version jump HKS and weapon-skill mapping. It includes 187 armor families / 741 named pieces, with rewards for 165 families, and restores official single-piece effects with the explicitly approved exceptions.

Core coefficients: sorcery/incantation attack power ×2.2, charged attacks ×3, jumps ×2, regular combo final hit ×3.5; guard counters ×4, criticals ×5, arrows/bolts ×2. Greatshield guard stamina consumption is ×0.5. Normal enemy stance durability is increased by 25% in 6,453 rows, excluding disabled and special high-value rows. Boss growth effects are preserved. Attack-power coefficients do not promise identical final HP damage ratios.

English item archives are updated. The Chinese JSON is merge-source text, not an installable Chinese archive. New changes pass static checks but require in-game testing. Install in a fresh ME3 directory, back up saves, disable EAC, start Steam, and launch `ModEngine\launchmod_eldenring.bat` offline. Own the base game and all DLC for complete content.
