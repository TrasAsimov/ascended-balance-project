# v0.10.2 · 全怪物处决接触参数修复测试

以官方 1.17.1 `ThrowParam` 的玩家对怪物 `throwType=20` 处决配对作为筛选条件，逐条审查当前包的全部 NPC 参数。官方没有对应处决配对的模型保持不变；有配对的模型恢复官方 `NpcParam.hitHeight`、`hitRadius`。Ascended 新增的同模型变体按同模型、同 `behaviorVariationId`、最接近 NPC ID 匹配官方参数。逐行结果见压缩包内 `审查清单/v0.10.2_all_npc_riposte_audit.csv`。

沿用 v0.8 已恢复的全部官方 `ThrowParam` 处决配对及失乡骑士、噩兆猎人的官方动画。其他怪物的 Ascended 动画包暂不整体覆盖，以免删除其新增招式或令行为引用失效。这次是完整参数审查和修复，不等于已在游戏中验证每一种动作；动画和地图事件仍可能影响特定变体的处决。若出现“弹反成功但无法处决”，请记下怪物名称、地点、普通版或 Ascended 新增变体、正面站位，以及是否先将其打出失衡。

安装：将压缩包内容按现有 v0.10.1 安装方式覆盖，确保使用包内的 `ModEngine/mod/regulation.bin`。建议先在不覆盖旧存档的环境测试失乡骑士、噩兆猎人、熔炉骑士，再测试其他之前失败的怪物。全部 7,187 条 NPC 均列入审查清单，未改处决以外的参数、动画和事件。
