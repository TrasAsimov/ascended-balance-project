## 实现与数值口径

只增加强化等级带来的**物理攻击力倍率**，+0完全保持。以下均为单手、相关属性99、不计心脏／装备／护符／附魔等外部增益的物理AR模型值，游戏取整可能相差少量点数；不是敌人受到的实际伤害。双持、动作倍率、防御和减伤另算。5000是看门犬杖的参考目标，不是所有特大武器的统一值或上限。

| 武器阶梯 | 类别 | 满强化相对当前物理AR |
|---|---|---:|
| 小型 | 短剑、拳套、爪、格斗、兽爪、投掷刃 | ×1.50（+50%） |
| 常规 | 直剑、曲剑、刀、双头剑、刺剑、斧、锤、连枷、矛、鞭、反手剑 | ×1.65（+65%） |
| 中大型 | 重刺剑、大矛、突刺盾、轻大剑 | ×1.75（+75%） |
| 大型 | 大剑、大曲剑、大斧、大锤、戟、镰刀、大刀 | ×1.80（+80%） |
| 特大 | 特大剑、特大武器 | ×1.886893（约+88.69%） |

通用武器原有的基础值、力敏智信感应系数、属性收益曲线、强化补正倍率及质变差异都保留；大蛇矛按下述例外处理。混合伤害武器只增强物理部分，魔力／火／雷／圣部分不变。并未把每种武器的面板强行统一。

普通锻造石武器L=25，失色锻造石武器L=10；使用实际源强化表的可用等级。若当前等级为l，所属阶梯满强化额外倍率为M：

`新增物理倍率(l) = 1 + (M-1) × l/L`

`新 physicsAtkRate(l) = 原 physicsAtkRate(l) × 新增物理倍率(l)`

因此+0新增倍率为1，满级达到M；中间等级逐级增加。强化用石、卢恩成本、强化上限、强化带来的异常累积与削韧／体能伤害维持输入，不赠送材料，也不减少所需探索。

模型公式为物理基础值×physicsAtkRate×（1+适用属性补正之和）；每项补正读取武器系数或AttackElementCorrect的覆盖值、reinforcement correctStatRate、物理CalcCorrectGraph的99属性端点与Influence系数。

不改法杖、圣印记、弓弩、箭弹、普通盾、火把、调香瓶与徒手。以enableMagic／enableMiracle保护能施法的混合武器及全部同族质变，包括卡利亚魔法剑与本Mod中启用施法的罗蕾塔战镰。保持施法补正、法术／祷告／战技耗蓝、法术参数、FP恢复、属性曲线与全部SpEffect。

部分NPC可能共用玩家武器行并携带强化等级，本次没有克隆NPC持武器引用以实现角色专属增益。若NPC实际用到本模块修改的武器与强化，应实测是否也获益；不能声称所有敌人实际攻击都保持不变。敌人参数表本身未改。

脚本重复执行会识别私有指针、回到仍保留的源组计算，不会再乘一次；非预期ID碰撞立即报错。当前模块只支持已核对的源组，未来加入其它强化组时应复核映射。

运行在05最终最新输入上，**不要用本候选整文件覆盖后来的职业或装备修改**：

```bash
export ARMOR_PARAMDEFS=/path/to/Paramdex/ER/Defs
# ARMOR_REGULATION_KEY_HEX由已有受控环境提供，不写入文档或源码
python scripts/boost_melee_reinforcement.py \
  --regulation /path/to/latest/regulation.bin \
  --item-bnd /path/to/latest/item_dlc02.msgbnd.dcx \
  --output /path/to/output/regulation.bin \
  --audit /path/to/output/melee_audit.json
```

item_dlc02只读武器名称，不修改游戏文本。本模块应排在原生武器异常恢复与其它武器参数模块之后，再运行整合验证。新职业使用的武器若为当前实际武器会自动获得对应阶梯，职业配置、初始材料和数量都不改。文档与审计包含所有受影响ID与对应源组，05同步玩家说明／CHANGELOG。
