# v0.4：原生 1.17.1 参数容器兼容测试

## 起因

用户测试 v0.3 时出现“Failed to save game / Save data is corrupted”。原版、关闭 MOD 加载器、移开 `ModEngine/mod/regulation.bin` 都正常，故将排查重点放在 v0.3 参数文件。v0.3 将 426 个新版行导入旧版 `11601000` 容器；此事本身尚不能证明存档已损坏。

## 改动

- 从用户提供的官方 1.17.1 `regulation.bin` 解密并以 `11711000` BND4 为基础。
- 184 张行大小相同的参数表沿用 v0.3 的共同行，并补入 10,894 个 Ascended 独有行。官方新版独有行保留；82 个新版武器强化行维持 `6202065` 常驻效果。
- 10 张行大小变化的表保留官方值：`EnemyCommonParam`、`GameSystemCommonParam`、`GraphicsCommonParam`、三张 `LoadBalancerNewDrawDistScaleParam`、`MenuCommonParam`、`MimicryEstablishmentTexParam`、`PlayerCommonParam`、`SfxBlockResShareParam`。这些表里的旧 MOD 改动尚未逐字段移植。
- 其余动作、怪物、地图、事件、脚本资产延续 v0.3。旧版资源与新版游戏的兼容性仍需要实测。

## 验证与风险

从输出 ZIP 读取的两份 `regulation.bin` 相同；ZIP 无损坏。解密后显示 `11711000`，194 张表可解析，所有保留或移植的行已逐字节回读。静态核验无法证明游戏内可读取存档。移植共同行的旧版整行也可能覆盖官方新版改动；后续应以 1.16 原版基线逐字段区分 MOD 差异与官方升级，再完成最终迁移。

测试时先备份 `%APPDATA%\EldenRing`，解压到全新 MOD 目录，从本包 `ModEngine/launchmod_eldenring.bat` 离线启动。先确认进入标题和角色，再测试开局职业、武器、法术与敌人的失衡、弹反。如果仍显示存档错误，立即停止使用并保留截图；不要删除存档。
