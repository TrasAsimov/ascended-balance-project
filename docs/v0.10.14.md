# v0.10.14 六护符测试版

用户明确要求先打包上传测试。本版为预发布，完整继承v0.10.13，添加Expanded Talisman Slots 1.1.6原DLL及slots=2的INI，ME2已登记加载。原生4＋额外2＝总6，记忆槽仍为8；不更改regulation、事件、动作或游戏文字。

## 安装与测试

备份存档，完整解压Ascended_Balance_v0.10.14_Six_Talismans_Test.zip到新目录，核对Release SHA256SUMS.txt。离线运行ModEngine/launchmod_eldenring.bat（Steam可用）。原生ME3须同时设置ModEngine/mod路径，以及实际profile的[[natives]]中DLL真实路径；INI与DLL放一起，勿重复注册。此项目没有修改用户本地ME3 profile。

1. 启动、读档、保存退出及重载。
2. 在赐福Expanded Talisman Slots菜单装备额外护符，确认总六槽、不能装备第七个。普通装备界面仍为四槽。
3. 用效果可观测且无同族冲突的护符测试第五／第六槽，分别装备、卸装、替换，确认增益生效和解除；核对背包、重量、同族互斥。
4. 传送、休息、死亡、退出重载、换角色后核对装备及效果。
5. 回归小壶战技+40%、莱昂提尔2～3件+10%／4件+20%全战技、护甲单件、心脏、核心平衡与高跳。分别测试BAT和原生ME3入口。
