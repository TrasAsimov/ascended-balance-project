# v0.5 待整合：玩家反馈与已准备的改动

用户已确认 v0.4 的紧凑版参数文件可以启动。测试时反馈四项：

1. 开局护符槽从预期 4 个退回 1 个。`PlayerCommonParam[0].baseAccSlotNum` 在 Ascended 旧版是 4，官方 1.17.1 为 1。v0.4 因行结构从 256 变为 264 字节，保留了新原版整行；v0.5 待测文件在新结构的字节 13 恢复为 4。现有角色的槽数可能另受存档状态影响；重点先测新角色。
2. 新职业名称及装备描述缺失。英语环境且 Tarnished Pack 已安装。新增职业 `BaseChrSelectMenuParam[2010,2011]` 和 `CharMakeMenuListItemParam[100210,100211]` 与官方 1.17.1 行完全一致；它们分别引用菜单文本 ID `288110/288111` 和 `297140/297141`。包内仍有旧版 `msg/engus/item_dlc01.msgbnd.dcx`、`item_dlc02.msgbnd.dcx` 覆盖，和当前官方文件不同；待测打包脚本移除这两份覆盖，让装备使用本地已安装的英文原版文本。职业菜单文本并无同名覆盖，缺失原因仍待定位，不能把“已修好”写入发布说明。
3. 武器战技恢复原版。共有 33 个官方武器参数行（包括强化阶段）的 `EquipParamWeapon.swordArtsParamId` 不同，待测文件仅恢复该字段；另外 255 个 `SwordArtsParam` 与 2 个 `EquipParamGem` 共有行恢复为官方 1.17.1 原值。保留武器其他字节，包括 1.5 倍常驻效果。MOD 独有武器 `60000001`、`60002001` 在官方版本中没有同 ID 参照，暂不改派。
4. 血、蓝、精力条过长。`MenuCommonParam[0]` 中 `playerMaxHpLimit`、`playerMaxMpLimit`、`playerMaxSpLimit` 是仅控制状态栏显示尺度的参数。将 1.17.1 原版值 `3565/825/480` 倍增为 `7130/1650/960`，减少显示长度；不会修改实际 HP/FP/精力。
5. 游戏内斧护符说明仍写“蓄力攻击提高 320%”。当前参数 `EquipParamAccessory[2130]` 引用 `SpEffectParam[321300]`，其物理、魔力、火、雷、圣攻击倍率均已由 Ascended 的约 `4.7` 改成 `1.5`。因此这条说明与现有改动不符；`1.5` 表示该效果层的约 50% 提升，最终伤害仍受适用条件与其他倍率影响。待定位实际生效的英文文本资源并统一校正相关道具说明，不能在未核对文本时把整个说明问题标成已修复。

`scripts/build_v05.py` 生成待测参数文件，完成静态回读：194 张表可解析，参数差异仅在前四项涉及的 5 张表；`scripts/package_v05.py` 已准备，但在职业菜单文本、道具说明及后续用户反馈整合前不发布完整包。
