# 武器恢复原版异常和固有效果显示

用户要求删除所有武器额外异常，原版是什么样就是什么样。图片显示“Causes blood loss buildup (0)”和“Causes sleep buildup (0)”。本模块以v0.10.8及刚完成的大盾护符80%减耗修正为基准，恢复武器固有异常的命中特效、显示条目与对应异常补正类型，去掉武器自带的额外毒／腐败附魔。不是清空原版所有出血／冻伤／毒等。

## 调查

v0.10.8 SHA256为`bf923783389021372e1d33d7bcc5e776c9b32e155af59f58fc0003142da44398`。官方参照来自已保存的重建检查点`Ascended_Armor_System_20261001_Rebuild.zip`中的1.17.1 `vanilla.bnd`及对应参数定义；最终输入为`01_Greatshield_80pct_20261002_regulation.bin`，SHA256 `af8aef4daa0cee52542cb64c19672e2e0539c914c8f0ea0b51d526899ebc35f9`；原v0.10.8相差仅该护符两字段。本候选保留最新80%修正，不是用旧独立候选覆盖最新参数。

当前武器命中槽的原始ID大部分已与官方相同，但对应共享SpEffect本体／链仍有修改。例如出血6401被改成持续30秒、每秒1%HP+200；毒6501和腐败6601也被改过。只恢复ID或删掉显示文字无法恢复这些武器效果。部分武器额外挂常驻3175/3179/3310/3314，命中累积毒或腐败100；面板额外指向6401/6450等文字，因此出现不存在实际对应固有效果的“0”条目。

## 最终修改

- 核查3638条武器参数行，含质变及特殊条目，不表示3638件不同的可用武器。1728条武器行发生变化。
- 三个`spEffectMsgId`显示槽按官方同ID逐项恢复，原版无异常的槽回到-1；保留原版固有异常文字。总计634个显示槽更改（329/304/1）。
- 三个武器命中槽按官方源恢复；原版状态根及全强化等级／子效果链使用490条私有官方SpEffect副本。固定偏移76,000,000，使`基础效果ID + 强化offset`仍可正确解析，不用顺序重新编号破坏强化。
- 923个额外异常常驻槽清除／恢复官方槽：毒3175共268、毒3179共267、腐败3310共195、腐败3314共192、额外6501共1。其它非异常常驻加成保留。
- 毒／出血／睡眠／发狂补正类型恢复官方，每种4条字段更改。武器其它字段不改。
- 两条Mod独有武器60000001/60002001没有官方同ID；按其明确`originEquipWep`1000000/1010000恢复对应原版异常配置，不删除武器本身。
- 现有全局属性成长、武器属性补正数值、强化倍率保持既有伤害平衡。本模块恢复武器原生异常基础值、命中特效时长／伤害／链与显示，不整体回滚全局伤害成长曲线。因此实战属性补正后的累积值不能凭本审计宣称在所有属性／强化等级都与纯原版完全相同。

共有SpEffect一行不改，以免还原武器时同时还原敌人攻击、涂脂、道具或祷告使用的同ID效果。原版正常涂脂／武器附魔使用方式仍保留，只移除武器自带的额外异常常驻。特殊战技／子弹本轮未整体回滚；无新增恢复战技或取消法术减半的指令。
