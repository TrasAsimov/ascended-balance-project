# 套装武器适用筛选修复（2026-10-02）

玩家反馈跳跃攻击、蓄力攻击、防御反击套装不生效，而处决及魔法套装生效。生成器对中性模板 1950 的奖励写入 wepParamChange=3；Smithbox ER 枚举标为 3=Self（自身）、0=None（无武器限制）；参数定义注明此字段控制武器适用范围。原版斧/爪/曲剑/双头剑护符对应选择器均为 0，处决与魔法模板沿用各自的正确筛选，符合这次症状。此前检查了奖励数值和事件，却遗漏武器适用筛选，这是生成器的错误。没有游戏内调试，不把静态定位宣称为全部词条的实机证明。

依据原版护符改为无武器限制的 0，同时保留魔法/祷告位和原攻击子分类。独立解密表体差分证明只改 234 个新增奖励的一个字节，涉及 148 个家族，所有其它参数行不变。数值、官方单件/例外、核心倍率、Boss成长、敌人参数不变。公共事件与两份英文档案的 SHA256 与 v0.10.7 一致。

检查全部 308 个根奖励的声明字段、武器/魔法/祷告筛选、子分类、处决位、佩戴者位与无覆盖类别；314 个奖励/子效果佩戴者位通过原检查。76 个蓄力/跳跃/防反/末段选择器与原版对应护符一致，左右手适用，玩家攻击表保留相应分类。原检查的 61,420 事件用例、15,620 换装场景、140 官方单件装备、167 官方链、26 套装意见/12 单件意见、741 护甲正文、PARAM/BND布局全部通过。verify_attack_filters.py --previous-bnd 可独立重现只改武器筛选的差分。

## 安装与实测

关闭游戏并备份存档及原 bin，将 02_Armor_Weapon_Filter_Fix_20261002_regulation.bin 重命名为 regulation.bin，替换完整 v0.10.7 的 ModEngine/mod/regulation.bin。不要换回旧公共事件。此为独立修正文件，没有生成新的 ZIP/Release；GitHub v0.10.7 原完整包仍不包含这次修正。

移除伤害护符、触发型增伤，保持同武器、同强化、同属性、同目标、同攻击和目标状态，每档读档并重复三次，记录伤害及失衡攻击次数。测试两件及满套、卸下一件、保存重载和死亡后的恢复；同类替换套装满套总值替换两件。防反需成功格挡后的真实防反，蓄力需完全蓄力的普通重击。两件削韧不能通过扣血数值判断，必须检查同一目标的失衡次数或姿态条。伤害会受防御/整数取整影响，不要求所有扣血恰好等于词条百分比。
