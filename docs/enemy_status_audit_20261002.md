# 敌人异常易触发调查（2026-10-02）

**结论：当前参数的主要问题在法术命中侧。大量魔法／祷告被额外附加异常累积，且部分法术增加弹数或命中后生成新的攻击子弹。不能用“所有 Boss 抗性条太短”概括。**

用户实测：只使用魔法和祷告，也能很容易给 Boss 上毒、冻伤。因此涂脂／投掷物不是本次反馈的直接解释；调查重点转为 Magic→Bullet→SpEffect／AtkParam_Pc 的实际引用。

## 敌人抗性侧

7025条双方共有且HP>0的NPC参数行并非7025种实际敌人，包含骨灰、友方、坐骑和变体。毒抗性6902条相同／80条降低／43条提高；冻伤7015条相同／1条降低／9条提高。降低的毒抗性大量属于骨灰和坐骑，不能据此宣称敌人整体抗性被砍。

这是基础字段，**不能直接当成该场战斗的最终异常阈值**；常驻特效、区域／周目与事件可能修正。区域抗性倍率示例7000／7040／7090与官方相同，分别为2／2.07／2.158（相应状态字段）。特殊玛尔基特行21300014多项基础抗性154→0是例外，尚未确认实际遭遇映射，不泛化到全部玛尔基特战斗。

ResistCorrectParam全部行逐字节与官方一致；七种状态的NpcParam抗性增长表引用改动均为0。不能说反复触发后的抗性增长被删除。常见NPC常驻90030保留咒死免疫、90060保留发狂免疫，累积与能否最终触发仍须分开。
