# Ascended 平衡优化版 v0.6 · 实机测试

本包以已发布且可启动的 v0.5 完整包为基础。保留其护符、武器战技、敌人血量、职业文本等改动；只更换两处 `regulation.bin`，其他游戏资源沿用 v0.5。

## 本轮改动

| 范围 | v0.5 → v0.6 | 核验重点 |
|---|---|---|
| 血条、蓝条 | 显示上限 HP 7130→28520、FP 1650→3300，缩短画面长度 | 无 BUFF、多个 BUFF 状态下是否仍完整显示；FP 数值另有下述调整 |
| 精力条 | 显示上限 960→1920，实际精力不变 | 与 HP／FP 的相对长度和可读性 |
| 玩家基础 HP | 玩家常驻效果 `6202065.maxHpRate` 1.5→2.0 | 同角色卸下额外生命护符、移除临时 BUFF 后核验基础血量 |
| FP 与消耗 | 常驻 FP 倍率 5→1；集中力成长曲线 50／70／99 级节点 500／700／900→450／550／650。法术和战技消耗不变，99 级集中力基准 FP 约 650 | 同一角色记录集中力、装备／BUFF、最大 FP，连续施放常用法术与战技的次数；法力瓶补给是否合理 |
| 卡利亚迅剑 | 将后续 5 个命中判定的魔力补正 100→200，与 Ascended 首段一致 | 比较首段和连续挥砍的单次伤害，控制距离、命中目标和装备 |
| 龙飨祷告 | 调整吐息 11 个主判定至约原版 1.5 倍、龙爪／龙咬／龙吼主判定至约 1.25 倍；持续命中、异常状态和 FP 消耗不变 | 分开记录第一段、持续伤害和异常状态伤害，确认普通和具名吐息都有用途 |
| 专属战技 | 蒙葛特咒剑、亵渎圣剑及基萨刺轮恢复武器端原版行为效果、主常驻效果和固定战灰限制；保留本版玩家常驻资源效果 | 新旧存档各试一次自带战技，检查动作、特效、回血／异常状态与战灰槽 |
| 基萨刺轮伤害 | 力量和灵巧补正 0／0→42／42，基础攻击力及强化数据保留 | 用相同强化等级、力量／灵巧、目标对比普通攻击及转轮攻击 |
| 失衡后的处决 | 恢复 12 条在 v0.5 迁移时丢失原版动作 ID 的 `ThrowParam` 整行，ID 详见 `changes/v0.6_changes.csv` | 先测官方本来可处决、当前却不能处决的敌人；原版无法处决的大型敌人不新增处决动作 |
| 过暗天气 | 15 种天气从强制引用浓雾光照配置 51 改为普通雾配置 50；永夜事件文件不动 | 夜晚是否保持、原先完全看不见路的区域是否改善、雨雪与远景是否正常 |

目前不能从第二张只有图标的截图唯一确定每个物品或效果 ID，因此没有擅自修改这 17 个图标对应的数值。需要游戏中选中图标后带名称和完整说明的截图，才能逐项核对文本、实际参数和触发条件。此项尚未完成。

## 安装与反馈

1. 备份存档，移走 v0.5 的安装目录。把此包完整解压到一个全新文件夹，不要覆盖合并旧版。
2. 继续采用之前已成功启动的离线 ModEngine 方式，保持 EAC 禁用。
3. 在同一角色、同一装备下记录 v0.5 和 v0.6 的 HP 数字、状态条长度和加 BUFF 后的长度。标出不能处决的敌人名字、地点、失衡动作与所用武器；记录过暗的具体区域与天气。

## 验证边界

本版已完成参数包解密、194 张参数表解析、修改范围逐行回读和 ZIP 完整性检查。法术的多段判定、武器战技动作、处决动作与敌人动画的配对、永夜与天气画面效果，都需要游戏内验证。第二张图所示图标的实际触发链还需带名称和完整说明的画面才能核对。若雾效仍使某地过暗或出现白天画面，请反馈地点和截图，下一版将按实际区域进一步处理。
