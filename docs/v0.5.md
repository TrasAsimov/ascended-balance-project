# Ascended 平衡优化版 v0.5 · 待玩家实机验证

本版基于已能在玩家当前游戏中启动的 1.17.1 原生紧凑参数容器。仍保留 Ascended 地图、事件、敌人行动、武器及其多数平衡设计。随机化尚未开始。

## 本次修复

| 范围 | 变化 |
|---|---|
| 开局护符槽 | 新角色初始可装备 4 枚护符；既有存档还可能受自身解锁状态影响。 |
| 英文职业和装备文字 | 加入玩家提供的当前官方英文菜单文本，含 Idus Knight、Heavy Knight 的名称及介绍；保留 Ascended 的道具文字，并补入新版 DLC 装备缺失的名字与描述。 |
| 武器原战技 | 官方已有武器 33 行的战技引用、255 行战技规则及 2 行战灰参数还原官方 1.17.1；Ascended 独有的两件武器缺乏官方参照，仍保留原设定。 |
| 状态条显示 | 显示尺度翻倍，血、蓝、精力条画面长度约减半；实际最大值不变。 |
| 怪物血量 | 恢复最初 Ascended 包中 1700 个怪物基础 HP 和 43 个区域血量倍率。新增的 6 行怪物在旧包里没有对应值，沿用官方数据。玩家自身的 1.5 倍 HP／伤害没有恢复到旧版高倍率。 |
| 护符 | 保留 Ascended 每枚护符的定位，修正明显不一致的说明和参数：斧护符 320% 旧说明改为当前的 50%；双头剑、箭矢刺痛、曲剑、蓝舞娘、壶友、葛孚雷肖像等文字同步；自定义 Magic Talisman 保留“魔法伤害提高 300%”目标，对应五种攻击属性系数由 5.0 调为 4.0；大山羊护符恢复韧性提升；大盾护符去掉额外受伤、改为格挡精力消耗减 10%；隐身面纱移除异常的察觉率提升。DLC 调香师与交叉树护符文案也同步。 |

护符各字段、调整理由和消息改动记录见 changes/v0.5_talisman_audit.csv、changes/v0.5_talisman_reconciliation.csv 和 changes/v0.5_message_edits.csv。文案描述的是对应的单层倍率；最终伤害与装备、敌人抗性、触发条件和其他效果叠乘。部分被动技能与事件触发无法只靠参数静态验证，以游戏实测为准。

## 安装

1. 备份当前存档及原 MOD 文件夹，并暂时移走先前 Ascended 测试版本的文件夹。
2. 解压此完整包到全新文件夹，不要与 v0.4 文件夹覆盖合并。按之前已成功进入游戏的离线方式，用本包中的 ModEngine/launchmod_eldenring.bat 启动。继续保持 EAC 禁用状态。
3. 游戏菜单选择英文进行文字核验。确认初始四护符槽、新职业英文名称与装备说明、斧护符 50% 文字，以及 Magic Talisman 300% 文字；在相同武器、角色与敌人条件下比较佩戴前后的伤害。
4. 选此前觉得过于脆弱的普通敌人和 Boss 验证血量，核对战技、法术、祷告、失衡及弹反。记录具体敌人、地点、招式和数值，便于下一轮修正。

## 静态验证与限制

参数包可解密、解压及解析全部 194 张参数表；除已列出的参数外，基础数据保持不变。消息包可完整解压，两个英文 DLC 消息包均包含修正后的护符说明；新版菜单资源包含上述两个职业名称与介绍；完整 ZIP 条目可逐个回读。这并不等于已经证明游戏内所有护符触发链、动作或文字载入优先级正确。当前环境不能运行玩家的 Windows 游戏，包交付后需实机验证。
