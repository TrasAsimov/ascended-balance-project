# 艾尔登法环 Ascended 平衡优化项目

当前完整测试版：[v0.10.9 最终整合版](https://github.com/TrasAsimov/ascended-balance-project/releases/tag/v0.10.9-final-integration)。

[English](README.md) · [版本摘要](CHANGELOG.md) · [开发文档索引](docs/INDEX.md)

基于Ascended的独立平衡项目，参数使用1.17.1格式。需游戏本体及全部DLC；随机化尚未制作。

## 当前功能

- 187个护甲家族、741件具名护甲，保留官方单件特色和兼容Mod效果；Effect分区标明套装件数。盗贼面罩归入猛禽/盗贼套，盾牌只保留效果。
- 蓄力额外+300%，魔法/祷告攻击力额外+220%；大盾护符使剩余格挡精力消耗减少80%，其他核心保持。
- 武器固有异常、显示及效果链恢复官方源，移除额外常驻毒/腐败；看门犬杖恢复安装适用战灰。
- 普通床帘恩泽120秒。恩惠蓝露滴10FP/s，已审计回蓝装备、星光碎片和拉塔恩回蓝5FP/s。
- 心脏手动刷新181场小首领成长及贝勒独立奖励；玩家法术正异常累积保持旧Mod的50%；清理额外惩罚并保留攻击异常。
- 初始四护符格、已批准成长及武器平衡、敌人韧性调整、夜色事件和原有跳跃脚本。

## 安装

1. 备份存档，从Release下载 `Ascended_Balance_v0.10.9_Final_Integration.zip`，核对 `SHA256SUMS.txt` 后解压到全新目录。自动生成的Source code ZIP不是MOD。
2. Steam可用时运行 `ModEngine/launchmod_eldenring.bat`，离线测试。ME3用户把mod目录指向 `ModEngine/mod`。只有一个实际regulation，没有根目录备份；不要混装旧文件或其他参数MOD。
3. 先验证启动、读档、保存退出再读档，再测战斗。`SHA256_FILES.txt` 提供运行文件校验和。

## 已知问题

新增模块仅静态/模拟检查通过，实机待测。英文文本已包含；中文JSON仅是合并源，尚缺匹配简中游戏档案。攻击力百分比不等同最终扣血增幅，复用玩家法术/效果的AI可能受影响；历史高跳实测不代表整包验收。见[当前测试步骤](docs/v0.10.9.md)。

源码、审计、对比和历史说明统一留在仓库开发索引，不进入玩家下载包。Ascended及游戏资源归原作者，本项目为独立优化。
